# Tallest hero

Скрипты для поиска самого высокого героя по API

## Использование функции
```python
get_tallest_hero("Male", True)
get_tallest_hero("Female", True)
get_tallest_hero("Male", False)
get_tallest_hero("Female", False)
```

## Тестирование функции
```bash
python test_tallest_hero.py 
```
